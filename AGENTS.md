# AGENTS.md — Persistent Project Rules & Instructions

## Mandatory Rules & Guidelines

1. **Mandatory Versioning (Обязательная Версионность)**:
   - Every single change, feature addition, bug fix, or code modification MUST increment the version in `package.json` by `0.0.1` (e.g., `0.0.1` -> `0.0.2` -> `0.0.3` ...).
   - The current version must be maintained across all project metadata, headers, build steps, and reported states.
   - Never skip or reset version increments.

2. **RICIS-III Engine Guidelines**:
   - Strict adherence to DRY, DDD, SOLID, and MVVM architecture.
   - Trace mathematical evaluations through Phases -1 to 6.
